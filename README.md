## What I'm Working On

**MSc Research — University of Ibadan**

rutting deformation in flexible pavements of Southwest Nigeria.

- 500-scenario synthetic dataset generated via automated PLAXIS 3D
- Python scripting against the PLAXIS remote API
- XGBoost regression trained on physics-based FEA outputs
- Hardening Soil constitutive model · Stratified Latin Hypercube Sampling
- Target: FEA-level accuracy at millisecond prediction speed
